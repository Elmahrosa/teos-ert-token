# teos-ert-token

Core ERT token contract (SPL token on Solana).

## Purpose

- Token metadata, mint/freeze authority handling
- Basic tests and deployment scripts
- On-chain asset that the TEOS Forge governance layer controls

## Structure

- `src/` — Token program source
- `tests/` — Unit/integration tests
- `scripts/` — Deploy, mint, authority-revoke
